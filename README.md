# 🌍 Multi-Agent Travel Planner

LLM-based multi-agent travel assistant for personalized trip planning built using Python, CrewAI, and LLMs.

An AI-powered multi-agent travel assistant designed to create smart and personalized travel plans using Large Language Models (LLMs), multi-agent collaboration, and automation workflows.

---

## ✨ Features

* Personalized trip planning
* Multi-agent collaboration system
* Destination recommendations
* Budget-based travel suggestions
* AI-generated itinerary planning
* Travel assistance automation
* Easy-to-use workflow

---

## 🛠️ Tech Stack

* Python
* CrewAI
* LLMs
* Google Colab
* GitHub

---

## ⚙️ Project Workflow

1. User enters travel requirements
2. AI agents analyze preferences and budget
3. Destination recommendation agent suggests places
4. Planning agent creates itinerary
5. Final travel plan is generated for the user
